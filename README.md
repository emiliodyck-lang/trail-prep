# Habits

A habit tracker where logging takes one tap. Offline-first PWA, no account, no backend.

Run it: `python3 -m http.server 8000` and open http://localhost:8000. On a phone, deploy it to any static host (GitHub Pages, Netlify) and use "Add to Home Screen".

See [DESIGN.md](DESIGN.md) for what's in it, what's left out on purpose, and why.
